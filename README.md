# Proyecto final Power BI

Proyecto realizado como trabajo final del **Curso Power BI IBM SkillsBuild – datahack**.

## Descripción
Análisis y visualización de un dataset proporcionado, desarrollado en **Power BI** y presentado en formato **PDF**.

El objetivo del proyecto es aplicar un flujo completo de análisis de datos, desde la preparación del dataset hasta la creación de dashboards orientados a la toma de decisiones.

## Contenido del proyecto
- Limpieza y transformación de datos
- Modelado de datos con **estructura en estrella (STAR schema)**
- Creación de medidas y cálculos en **DAX**
- Diseño de visualizaciones y dashboards interactivos

## Archivos incluidos
- **sofiaserantes.pdf** → Dashboard final exportado en PDF  
- **sofiaserantes.pbix** → Archivo editable de Power BI  
- **DEFINE DAX.txt** → Medidas DAX utilizadas en el proyecto

## Herramientas utilizadas
- Power BI
- DAX
